# Meu Primeiro PR

Este é um repositório de prática, criado para aprender o fluxo de contribuição no GitHub: branch, commit, push e Pull Request.

## O que este projeto faz

Nada de especial — ele existe apenas para você pratricar o fluxo de trabalho com Git e GitHub.

## Como contribuir

1. Crie uma branch a partir de `main`.
2. Faça sua alteração.
3. Abra um Pull Request descrevendo o que mudou e porquê.

Obrigado por contribuir!
